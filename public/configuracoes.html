🌐 Endereço do Servidor

Configure o endereço IP e porta do servidor Node.js. Útil quando o frontend está sendo acessado por outro dispositivo (ex: celular na mesma rede Wi-Fi).
Deixe em branco para usar o mesmo servidor que está servindo esta página (window.location.origin).

Formato: http://IP:PORTA — sem barra no final

⚙️ Configuração do ESP8266

No firmware do ESP8266, configure os parâmetros abaixo para que o leitor se comunique com o servidor:

// Wi-Fi
const char* ssid = "SUA_REDE_WIFI";
const char* password = "SUA_SENHA_WIFI";

// Servidor
const char* serverUrl = "http://<IP_DO_SERVIDOR>:3000/verificar";

Substitua <IP_DO_SERVIDOR> pelo IP da máquina que roda o Node.js. Certifique-se de que o ESP8266 e o servidor estão na mesma rede.
